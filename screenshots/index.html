書き出し方法（Chrome）
1. Chrome で このページを開く
2. DevTools を開く（Cmd+Option+I）
3. 上部のデバイスアイコン（Cmd+Shift+M）をクリックしてデバイスモードに切替
4. 解像度を 430 × 932 に設定 → DPR を 3 に設定
5. ⋮ メニュー → 「Capture screenshot」 または 「Capture full size screenshot」
   → 1290×2796px の PNG が書き出されます
6. 各スクリーンショットを個別に切り取る場合は、画面をスクロールして各セクションを表示した状態でキャプチャしてください。
