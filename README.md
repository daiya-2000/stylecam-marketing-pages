# StyleCam Marketing Pages

This folder contains the minimum files for a dedicated public GitHub Pages repository.

## Repository Name

Use this name for the new public repository:

stylecam-marketing-pages

## Files

- index.html: marketing URL landing page for App Store Connect
- app-ads.txt: AdMob domain authorization file

## Publish Steps

1. Create a new public repository named stylecam-marketing-pages.
2. Copy these files to the repository root.
3. Push to main branch.
4. In GitHub repository settings, open Pages and set:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
5. Wait for publication.

## Expected URLs

- https://daiya-2000.github.io/stylecam-marketing-pages/
- https://daiya-2000.github.io/stylecam-marketing-pages/app-ads.txt
