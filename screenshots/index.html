書き出し方法（Chrome DevTools）
1. Chrome でこのページを開く
2. Cmd+Option+I → DevTools を開く
3. Cmd+Shift+M でデバイスモードに切替
4. サイズを 430 × 932 に設定 → DPR を 3 に変更
5. 各スクリーンショットまでスクロール → ⋮ → Capture screenshot
  → 1290×2796px の PNG が書き出されます
⚠️ 04 (美肌フィルター) のみ、実機でスクリーンショットを撮って
img/screenshot-beauty.png として保存してから書き出してください。
撮り方: アプリ → 参考画像を選択 → 美肌スライダーを適度に動かした状態でスクリーンショット
